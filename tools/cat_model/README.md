# Cat model (tools/cat_model)

The orchard's walking cat (`orchard/public/models/cat.glb`) is **generated by
us** — procedurally, with trimesh + numpy — not downloaded from any asset
store. It replaced the voxel placeholder cat that shipped with the original
orchard prototype. The reference screenshots live in `sketches/cat/cat1`
(walking-trot proportions, hooked upright tail, fur texturing).

## Regenerate

```sh
cd orchard  # any dir works; the script is standalone
../../wiese/.venv/bin/python tools/cat_model/build_cat.py brown cat.glb
# (or `black` for the dark variant; second arg = output path)
```

Then copy the result over `orchard/public/models/cat.glb` (the script embeds
the fur PNG into the GLB; the loose `cat_v26_fur.png` is the current texture
for reference/inspection only).

## How the model is built

- **Body = lofted tube**, not stacked ellipsoids: elliptical cross-sections
  (width `rx`, height `ry`) swept along a spine defined by `BODY_CTRL`
  control points (`y, z, rx, ry`) with PCHIP interpolation. Deep chest →
  slight waist dip → firm pelvis → rounded rear; a second loft
  (`NECK_CTRL`) links the withers to the head pivot.
- **Node tree** (`cat` → `body`, `head`, `tail`, `leg_fl/fr/hl/hr`): every
  leg is a separate mesh node whose geometry is re-cent on its **hip pivot**
  (top of the limb), tail and head likewise. This is what allows the
  procedural walk in `orchard/src/cat.ts` to swing the legs, bob the body,
  sway the tail and nod the head without a skinned mesh or animation data in
  the GLB (the file ships clips-less; cat.ts synthesizes `walk`/`idle` from
  the node names).
- **Fur texture**: procedural 1024×1024 PNG (`fur_texture()`) — value-noise
  mottling, cream belly band (low v), wavy tabby stripes (high v), dark
  spine. Mapped with a cylindrical unwrap (u = azimuth, scaled to u<0.70 so
  the right texture strip stays free); eye/nose get dedicated UV patches
  (`PATCH_RECTS`) painted by `feature_patches()`.
- **Face**: eyes = cream half-dome sclera + green iris dome flush in it +
  narrow vertical slit pupil boxes proud of the iris; muzzle-tip nose stud
  embedded (no gap).
- **Rigid-node blending caveat**: legs/tail are separate nodes, so there is
  always a small crescent where a leg tube exits the body skin. Do **not**
  try to fix that with blob "sleeves"/deltoid caps at the shoulder — those
  read as bolted-on dark slabs; instead cap the tube top (hip cap blob),
  keep the root slim and the pivot deep inside the torso, and let the loft
  carry the shoulder/haunch mass (`haunch_l/r` blobs stay in the body node).

## Aspect pitfalls (each cost an iteration)

- glTF flips textures: paint the texture, then `Image.FLIP_TOP_BOTTOM`
  before embedding, or belly/spine colors land inverted.
- Cumulative face offsets when concatenating primitives must be
  `sum(len(prev verts))`, not the part count.
- An icosphere squash with `subdivisions=0` renders as a flat star slab;
  use ≥1 for anything visible.
- Muscle mass comes from extra bulge blobs + finer ring sections (14–20),
  not from tapering the tube alone.
- One explicit sign convention (+z forward) for front AND rear feet —
  deriving the rear paws by negating gives paws pointing backwards.
