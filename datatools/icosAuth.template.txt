Template for datatools/icosAuth.txt (NOT in git when real) — the ICOS login
cheatsheet. Copy to datatools/icosAuth.txt and fill in your real values.

How the pipeline uses it: refSensors.py itself does NOT read this file. It
reads the cpauth token config at ~/.icoscp/cpauthToken_auth_conf.json
(auto-refreshing). This cheatsheet documents how to create that config:
log in once at the ICOS cpauth service with your account, receive the
AuthToken JSON, and save it to the config path below.
